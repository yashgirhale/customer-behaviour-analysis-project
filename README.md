# Customer Shopping Behavior Analysis

## Project Overview
Analyzed 3,900 customer shopping transactions to understand purchasing patterns, customer preferences, spending behavior, and subscription trends.

## Tools & Technologies
- Python (Pandas)
- MySQL
- Power BI

## Project Workflow
- **Python:** Data cleaning, handling missing values, feature engineering, and exploratory data analysis.
- **MySQL:** Analyzed customer spending, product ratings, discounts, subscriptions, shipping preferences, and customer segments.
- **Power BI:** Created an interactive dashboard to visualize sales trends and customer behavior.

## Key Business Insights
- Compared revenue by gender and age group.
- Identified top-rated and most-purchased products.
- Analyzed discount usage and subscription behavior.
- Segmented customers into New, Returning, and Loyal groups.
- Compared Standard and Express shipping performance.

## Business Recommendations
- Encourage customer subscriptions.
- Introduce customer loyalty programs.
- Optimize discount strategies.
- Promote top-rated products.
- Focus on targeted marketing.

## Conclusion
This project demonstrates an end-to-end data analytics workflow using Python, MySQL, and Power BI to transform raw customer data into meaningful business insights.
